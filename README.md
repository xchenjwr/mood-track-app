#### 一句话描述app

这是一个基于 uni-app + Vue3 + Pinia 的 “情绪记录/情绪追踪”应用，支持用户自定义情绪类型、记录情绪事件，并用图表查看统计趋势。

#### 具体说明
对象（Profile）管理：支持多个“对象/分组”（比如“个人”“朋友A”），可新增/改名/删除/切换，还支持把某个情绪整体转移到别的对象（**ai编程**）。  
情绪（Emo）管理：在当前对象下创建情绪、改名、删除；首页按“记录次数”降序展示。  
情绪记录（Record）管理：给某个情绪新增记录（描述+时间）；在详情页按时间查看；支持编辑/删除；支持把某条记录转移到另一个情绪。  
统计页（Stats）：展示趋势图表（不同对象对比、单对象下 Top5 情绪趋势），并支持近一周/近一月/近三月/自定义区间（**ai编程**）。  
数据导入/导出（设置页）：导出当前数据为 JSON、导入 JSON 并解析到应用；并带旧数据结构迁移到 v2。
